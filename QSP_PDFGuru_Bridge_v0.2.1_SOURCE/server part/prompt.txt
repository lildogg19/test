Распознай прикреплённый счёт на оплату из Казахстана за ОДИН проход: реквизиты и ВСЕ товарные строки. Верни полный валидный JSON внутри единственного блока кода ```json ... ```. Вне блока ничего не пиши. Не вызывай инструменты конвертации. Не изменяй исходный файл.
Правила: извлекай только видимые значения, нечитаемые или отсутствующие поля — null. Поставщик и покупатель — соответствующие стороны документа; БИН/ИИН только напечатанные цифры, строкой. Для каждой стороны отдельно извлеки только явно напечатанные адрес, КБЕ, ИИК/IBAN, наименование банка и БИК. Не переноси банковские реквизиты от одной стороны к другой. Номер — номер текущего счёта, дата YYYY-MM-DD, валюта KZT если указаны тенге. Товарные ячейки должны принадлежать одной физической строке. Не включай итоги, подписи и печати в items. Сохрани номера строк, название, артикул, единицу, количество, цену и сумму буквально, без вычисления отсутствующих значений. total_quantity — только напечатанный итог количества, не сумма количества по строкам. subtotal — только отдельно обозначенный итог без НДС, не подставляй туда total. vat_mode: "without_vat" при явной надписи "Без НДС", "with_vat" при явно указанном НДС, иначе "unknown". Не заменяй "Без НДС" ставкой 0%. Значения сумм и количества — JSON-числа; номера, БИН и артикулы — строки. Сохрани ключи с подчёркиваниями без изменения; кавычки внутри строк экранируй.
