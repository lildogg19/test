# API для расширения 1С

Каждый запрос требует заголовок `X-QSP-Token`. Ключ генерируется установщиком и хранится в `.env` сервера и настройке расширения 1С. Пароль PDF Guru через API не передаётся.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | Версия сервиса |
| POST | `/jobs` | Поставить файл в очередь: base, actor, request_key, filename, content_base64 |
| GET | `/queue?base=...` | Общий статус обработчика, задания этой базы, позиции, последние 50 заданий |
| GET | `/jobs/{id}?base=...` | Статус, исходное распознавание, ошибки и актуальное сопоставление |
| POST | `/references` | Полная актуальная выгрузка suppliers, organizations, items для base |
| POST | `/jobs/{id}/confirm-matches` | Подтверждённые пользователем supplier_id, organization_id, item_ids и base |
| GET | `/jobs/{id}/confirmed?base=...` | Подтверждённое сопоставление после проверки актуальности справочника |
| GET | `/jobs/{id}/source?base=...` | Исходный файл для прикрепления в 1С |
| POST | `/jobs/{id}/imported` | Зафиксировать GUID реально созданного счёта: base, document_id |
| POST | `/jobs/{id}/retry?base=...` | Ручной повтор ошибочного задания или возобновление после входа |

request_key должен сохраняться при повторе того же HTTP-запроса после сетевого сбоя. Новая загрузка другого файла требует нового request_key. В расширении ключ генерируется для отправки; при неопределённом результате сначала обновите очередь, прежде чем заново загружать файл. Импорт того же задания в 1С защищён отдельным регистром.

Справочники передаются с постоянными GUID 1С; помеченные на удаление записи и группы исключаются. Массив items включает id, name, sku, unit, unit_id и service. Соответствия привязаны к base, поставщику и исходным наименованию/артикулу/единице. Суммы и реквизиты OCR при сопоставлении не меняются.

Состояния: queued, processing, awaiting_login, failed, completed, imported. completed означает готовый ответ для проверки, а не автоматически подтверждённый документ. imported означает непроведённый счёт, созданный по действию бухгалтера.
